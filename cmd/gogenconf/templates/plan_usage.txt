Usage: gogenconf schema plan [flags...] [file]

Inspect the generation plan without writing files

Reads a declarative schema document and displays the resolved multi-file generation plan.
Alias for `gogenconf plan`.

Examples:

gogenconf schema plan --schema schema.conf
gogenconf schema plan schema.conf --json

Subcommands:
    help         Print this help message
    usage        Print this usage message


Flags:
    --schema string      (default: "")      Path to declarative schema document
    --out string         (default: ".")     Target output directory
    --pkg string         (default: "")      Target Go package name
    --readable, --json   (default: false)   Output machine JSON plan
    --runtime, --free    (default: false)   Include standalone dependency runtime in plan
    --sample             (default: false)   Include sample document in plan

Positional Arguments:
    [file]     Positional schema document path
