Usage: gogenconf schema list [flags...] [file]

Inspect schema sections, fields, and types

Reads a canonical declarative schema document and displays its sections, fields,
Go mapping types, defaults, and policy flags in a structured outline.

Examples:

gogenconf schema list --schema schema.conf
gogenconf schema list schema.conf --json

Subcommands:
    help         Print this help message
    usage        Print this usage message


Flags:
    --schema string      (default: "")      Path to declarative schema document
    --readable, --json   (default: false)   Output machine JSON format

Positional Arguments:
    [file]     Positional schema document path
