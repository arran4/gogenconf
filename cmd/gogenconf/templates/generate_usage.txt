Usage: gogenconf generate [flags...] [file]

Generate Go models and bindings from a schema

Reads a canonical declarative schema input and emits strongly typed Go configuration
models, binders, and optional dependency-free runtime code.

Examples:

gogenconf generate --schema schema.conf --out ./config
gogenconf generate schema.conf
gogenconf generate --check --schema schema.conf --out ./config
gogenconf generate --clean --schema schema.conf --out ./config

Subcommands:
    help         Print this help message
    usage        Print this usage message


Flags:
    --schema string     (default: "")      Path to declarative schema document
    --out string        (default: ".")     Output directory for generated artifacts
    --pkg string        (default: "")      Target Go package name
    --check             (default: false)   Check generated output without modifying files
    --clean             (default: false)   Remove obsolete generated files
    --runtime, --free   (default: false)   Emit standalone dependency runtime AST and parser
    --sample            (default: false)   Emit sample configuration document

Positional Arguments:
    [file]     Positional schema document path
